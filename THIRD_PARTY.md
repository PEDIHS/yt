# Third-party UI and visualization references

This project uses or draws design inspiration from the following open-source projects.

## Runtime libraries

### Apache ECharts
- Project: https://github.com/apache/echarts
- Purpose: interactive analytics charts in the web panel
- License: Apache License 2.0
- Loaded in the panel from jsDelivr CDN.

### Lucide
- Project: https://github.com/lucide-icons/lucide
- Purpose: interface icons
- License: ISC
- Loaded in the panel from a CDN.

## Design references

The panel's custom Flask/Jinja CSS is influenced by common layout and UX patterns found in:

### Flowbite Admin Dashboard
- Project: https://github.com/themesberg/flowbite-admin-dashboard
- License: MIT
- Referenced for dashboard information hierarchy, responsive admin patterns, KPI cards, data tables and navigation concepts.

### shadcn-admin
- Project: https://github.com/satnaing/shadcn-admin
- License: MIT
- Referenced for modern admin dashboard density, card hierarchy and interaction patterns.

The application does not vendor or copy these full templates. Its markup and CSS are maintained specifically for this Flask project.
